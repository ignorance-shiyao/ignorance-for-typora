# Ignorance Advanced

给 Typora 增加演示面板、行内徽章与彩色高亮、图表索引侧栏、中英文空格格式化，以及周报与汇报模板。

## 内容

| 功能 | 说明 |
|---|---|
| 演示面板 | 在详情栏把当前文档按 `---` 或标题分页；支持版式注释、脚注、图标短码、KaTeX 公式；可全屏放映 |
| 演示里的图表 | 内置绘制，不依赖图表库。` ```echarts ` 代码块支持 bar、line、pie 的常用选项，其他类型显示源码并给出原因 |
| 演示里的流程图 | 内置绘制。` ```mermaid ` 代码块支持 `graph` 和 `flowchart`（节点、箭头、连线文字、回路），其他 Mermaid 图与 `subgraph` 显示源码并给出原因 |
| 行内徽章与高亮 | `((green:构建 \| 通过))`、`((spoiler:...))`、`((ruby:...))`、`((crumb:...))`，以及 🔴🟠🟢🔵🟣 彩色高亮 |
| 图表与图片侧栏 | 按标题列出文档里的代码块、表格、公式与图片 |
| 格式化 | 中英文之间加空格 |
| 片段与模板 | 徽章、图表片段；周报、汇报模板 |

编辑器里的 ` ```mermaid ` 由 Typora 自带渲染；` ```echarts ` 在编辑器里显示为代码，只在演示里出图。

## 权限

只声明 `document: read`，用于演示面板和侧栏读取当前文档，不联网，不写文件。

## 第三方库

以下库原样取自各自的发布包，未做修改，许可文本放在同一文件夹。

| 库 | 版本 | 许可 | 用途 | 文件 |
|---|---|---|---|---|
| KaTeX | 0.16.11 | MIT | 演示里的数学公式 | `vendor/katex/` |
| Lucide（Iconify 打包） | 待确认 | ISC | 演示里的图标短码 | `vendor/lucide-icons.js` |

两者是上游发布的压缩版本；本扩展自己的代码都是可读源码。
