# Ignorance Outliner

Move and re-indent Markdown list items with their children. The UI is in Simplified Chinese.

用于 Typora 2.0 的列表大纲命令。光标在列表项里时，命令连同全部子项一起处理，记为一次撤销。

## 命令与快捷键

| 命令 | 快捷键 |
| --- | --- |
| 上移列表项 | `⌘⇧F7` |
| 下移列表项 | `⌘⇧F8` |
| 提升列表层级 | `⌘⇧F9` |
| 降低列表层级 | `⌘⇧F10` |

另有：将选中文本转换为列表，将选中列表转换为标题，查看列表分支，查看列表前几层。有序列表移动后序号自动重排，任务列表的勾选状态保持。

侧栏「列表大纲」显示当前列表分支，可选中后复制。

## 权限

| 权限 | 用途 |
| --- | --- |
| `document: write` | 把列表改动写回当前文档 |

不联网，不读工作区。

## 已知限制

- 不支持拖拽排序和行内折叠箭头，Typora 的扩展接口不开放编辑器 DOM。
- 快捷键用功能键，其他系统上可能与系统快捷键冲突。
- 与 `Ignorance Advanced` 同时启用时会出现重复的命令和快捷键，请只启用其中一个。
