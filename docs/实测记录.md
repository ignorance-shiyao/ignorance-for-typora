# Typora 实测记录

本机环境为 macOS 27.3，Typora 2.0.0-beta1。实测仅使用虚构样例的临时副本。

## 第 1 项 Markdown 规则整理

运行 `scripts/build-store.sh`，用 `diff -qr advanced/ignorance.advanced store/extensions/ignorance.advanced` 确认包内文件一致。本机已通过符号链接安装该扩展，链接指向同一份源码。因此在「设置 → 扩展」点击「重新加载」，沿用原链接。全新安装可在同一界面通过「从文件安装」选择生成的扩展目录。[Typora 扩展安装说明](https://docs.typora.io/extensions/quick-start#_2-install-it)

在独立窗口打开 `tests/fixtures/markdown-lint.md` 的临时副本。使用 Typora 无障碍树确认命令和值，保存临时文件后用 `cmp` 和 Node 断言比较内容。扩展设置的列表开关测后恢复为开启。

构建并比对商店副本，使用 Typora 新窗口加载扩展，在 `tests/fixtures/outliner.md` 的临时副本实测。使用宿主块树核对列表项父子关系，并整篇一次写回，源文档中只改动目标列表。提升中间子项时将它放到原父项整棵子树之后，避免原来的后续兄弟项被错误改挂到它下面。

列表分支提供只读预览。Worker 公开接口可读取选区和替换内容，缺少设置选区入口，因此还不能在编辑区自动选中分支。最大层数通过独立预览设置，详情页提供按标题分组的列表索引。前两层和分支内容由纯函数测试核验，宿主无障碍树只确认了弹窗与首条，完整条目和两种转换命令仍待实测。[Typora Worker API](https://docs.typora.io/extensions/worker-api#editor)

## 第 4 项 中文自然语言日期

按同样方式重建扩展，在新的 Typora 窗口打开 `tests/fixtures/natural-date.md` 的临时副本。宿主系统日期为 2026-11-22，默认周一起算。以运行时本地日历日期为基准，再按公历日计算，避免夏令时切换影响跨日结果。无年份月日采用基准年份；相对月份遇短月取月底；「周末」取该周周六。
