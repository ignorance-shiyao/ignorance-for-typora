本机环境为 macOS 27.3，Typora 2.0.0-beta1。实测仅使用虚构样例的临时副本。

### 实现选择

- 索引每批读取 16 个文件，按内容哈希复用未变笔记。Typora 只返回最多 5,000 条路径，没有截断前总数。达到该值时明确提示扫描上限，目录上限在主动重建时也会提示。
- 属性查询、任务与图表采用互动 resolver 加 SVG 快照，避免给只读扩展增加写权限。快照超时或结果过大时展示原始查询文本。真实导出结果待验证。
- 本周任务定义为从今天起的 7 个日历日。表格里点击文件名会显示相对路径，能直接跳转的条件等 V1 验证。
- 搜索预先建立倒排索引，文件名和标题权重大于正文。中文单字用于候选交集，连续双字用于加分，因此分开的词也能找到。搜索侧栏按文档上下文发送和读取请求。复验命令为 `node scripts/benchmark-vault-search.mjs`。
- 关系解析优先同目录，再比较路径距离，距离相同按相对路径顺序确定。它只把 Markdown 笔记和 Wiki 引用作为内部出链。
- 复习把四档评分映射为 SM-2 的 0、2、4、5 分。Worker 使用扩展存储的原子更新和卡片版本校验避免重复记分，评分不写回源笔记。

第 5 至 11 项各有 10 组边界探测。执行 `node scripts/probe-vault.mjs` 可打印 70 条含输入、实际结果和判定的 JSON Lines 证据。
